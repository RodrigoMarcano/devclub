# devclub — Estudos de HTML e CSS

Exercícios e projetos feitos durante a formação de front-end do [DevClub](https://devclub.com.br), da estrutura básica de uma página até layouts responsivos.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## Projetos

| Pasta | Conteúdo |
| --- | --- |
| [cssProjeto1-html](./cssProjeto1-html) | Landing page de um pet shop fictício, com cabeçalho, seções e imagens |
| [cssProjeto2_responsividade](./cssProjeto2_responsividade) | Página responsiva, que se adapta a telas menores com media queries |
| [Desafio1](./Desafio1) | Desafio de reprodução de layout a partir de um modelo |

## Exercícios

| Pasta | Conteúdo |
| --- | --- |
| [html](./html) | Aulas de HTML numeradas: tags, estrutura, SEO, links, listas, imagens, tabelas, vídeo, iframe e formulários |
| [css](./css) | Seletores, cores e estilização básica |
| [Pseudoelementos](./Pseudoelementos) e [Pseudo elementos](./Pseudo%20elementos) | `::before`, `::after` e outros pseudoelementos |
| [!important](./!important) | Uso e prioridade da regra `!important` |

## Como visualizar

Não é preciso instalar nada. Baixe o repositório e abra o arquivo `index.html` de cada pasta no navegador:

```bash
git clone https://github.com/RodrigoMarcano/devclub.git
```
