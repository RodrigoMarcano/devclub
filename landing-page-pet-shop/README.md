# We Care — Landing page de pet shop

Página inicial de um pet shop fictício, construída com HTML e CSS a partir de um layout proposto no curso do DevClub.

🔗 **[Ver página online](https://rodrigomarcano.github.io/devclub/landing-page-pet-shop/)**

![Prévia da landing page We Care](./preview.png)

## Sobre o projeto

A página tem um menu de navegação com botão de login e uma seção principal (hero) com ilustração, título, texto de apoio e botão de chamada para ação. O objetivo foi reproduzir fielmente o layout, trabalhando tamanhos, espaçamentos e hierarquia de textos.

## O que pratiquei

- Estrutura semântica com `header`, `main` e `section`
- Reset de CSS com `box-sizing: border-box`
- Tipografia com fonte externa (Montserrat, do Google Fonts) e hierarquia de títulos
- Estilização de botões: bordas arredondadas, cores e sombra com `filter: drop-shadow`
- Alinhamento de imagem e texto lado a lado com `inline-block`
